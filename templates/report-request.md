# 新汇报请求

> 不必填表。直接说明“给谁、什么情况、想达到什么目的”，再贴零散事实也可以。未知信息可以保留未知。

- **对谁说**：关系、对方已经知道的背景。
- **这次的目的**：同步信息、请求决定或协助、提醒风险、展示成果等。
- **已有事实**：做了什么、结果是什么、哪些还在推进；数字或结论不确定时请注明。

## 可选条件

- 情景：日报 / 阶段进度 / 成果 / FYI / 其他，可多选
- 渠道与长度：私聊、群聊、邮件、文档、口头稿；大概多长
- 关键风险、依赖或卡点：
- 后续动作：谁负责、何时完成；区分计划、估计与已经承诺
- 需要对方做什么、最晚何时决定：
- 这次特别想强调或避免什么：
- 想参考哪一条历史样本，或者这次有什么不同：
- 是否有已有草稿：

## 助手使用说明

优先根据现有信息推进，机器标签由助手整理。只对会影响事实、结论、承诺或关键请求的缺失信息作必要澄清；不能用虚构内容填空。可以先写不依赖缺失信息的部分，并将待确认项与可发送正文分开。

写汇报不包含发送消息或替用户执行承诺。用户另有明确发送或操作要求时，按该要求和实际授权处理。
