# 历史汇报样本

> 提示卡：可以直接用自然语言发来，不必填满。不知道或不记得就写明。保留真实措辞，敏感内容用一致代号替换。

## 当时的情况

- 对谁说、是什么关系：
- 对方已经知道哪些背景：
- 当时发生了什么：
- 这次想让对方知道、决定或做什么：

## 实际发出的原文

在这里粘贴原文，保留换行、称呼、标点和表情。如为连续对话，注明说话人。

## 当时为什么这样写

自由解释即可，例如：为什么先讲这一点？哪些已知事实没有写？为什么提出或没有提出请求？哪些措辞是刻意选择的？不记得的部分无需推测。

## 可选补充

- 我觉得这份稿子：很像我 / 一般 / 当时妥协 / 不应照学 / 说不清
- 原稿或别人写的版本：
- 我最终改动了什么、为什么：
- 对方的实际反馈（没有或不知道都可以）：
- 现在回看希望怎么改（与当时的想法分开）：
- 大致时间、发送渠道：
- 来源或外部约束（如组织模板、领导要求）：

## 助手整理栏（用户无需填写）

- 样本 ID：
- 对象 / 目的 / 情景标签（允许多选和未知）：
- 事实与不确定信息：
- 用户明确解释的取舍：
- 待确认的观察及其他可能解释：
- 学习用途：校准素材 / 未进入规则提炼的保留样本 / 仅反例

不得把助手的观察写成用户已经确认的偏好。若要将此样本作为保留评估材料，应在开始提炼前确定用途，并避免把目标原文提供给负责生成的评估者。
