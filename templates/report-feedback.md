# 汇报反馈

> 最省事的方式：直接贴你改好的版本，再说“这两处不像我”。无需逐项评分。

- 整体：可直接发 / 小改可发 / 需要重写 / 尚未判断

## 我最终采用的版本

粘贴终稿；如果只是局部调整，贴修改前后的片段也可以。

## 最值得记住的修改

- 修改了什么：
- 为什么改：事实不对 / 重点不对 / 目的不清 / 语气不像 / 太长或太短 / 其他
- 这是通常偏好，还是只适用于本次或某种场景：不知道也可以

## 可选反馈

- 最像我的地方：
- 最不像我的地方：
- 对方的实际反馈：
- 这次新增或更正了哪些事实：

## 助手整理栏（用户无需填写）

- 对应请求或输出 ID：
- 事实修正：
- 明确确认的偏好及适用条件：
- 仍需观察的候选规则：
- 与已有规则的差异、可能原因：
- 本轮是否可用于独立评估：

先完成本次修改，再更新有依据的规则。不要把每次临时改动都升级成通用要求；一旦用该反馈更新了规则，同一任务的重写结果就不再属于独立验证。
